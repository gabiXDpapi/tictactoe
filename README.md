# 🎮 TicTacToe Game

A simple **TicTacToe** game built with [React](https://react.dev/) and [Vite](https://vitejs.dev/).  
This project helped me practice component modularization, state management, and TypeScript basics.

---

## ✨ Features
- ✅ Playable TicTacToe board (2 players)
- ✅ Highlights the winner
- ✅ Reset / Restart functionality
- ✅ Modularized React components
- ✅ Built with **Vite + React + TypeScript**
